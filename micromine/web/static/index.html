1. Upload genomes

One FASTA file per species. Upload one file to annotate its SSRs only, or two or more to compare species. The order below sets the order of the species in the report and in the figures; the first species is the reference genome (SSR numbering and zoom coordinates). Drag rows or use the arrows to reorder.
