THANNYA — versão 1.4.0

Esta distribuição contém a identidade THANNYA e as correções de tratamento de bases N.

Estrutura principal:
- thannya/: pacote Python, algoritmos, interface web e recursos estáticos
- tests/: testes automatizados
- docs/: documentação e figuras
- public/: arquivos estáticos para implantação serverless

Instalação local:
  pip install -e "[web]"

Linha de comando:
  thannya -i pasta_com_fastas -o resultados

Servidor web local:
  thannya-web --port 8000

Antes de publicar, execute os testes automatizados e confira os comandos de build/start configurados no serviço de hospedagem.
